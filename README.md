# الغرف الحقيقية المغلقة

لعبة غرف تحدٍّ مبنية بـ React.js مع مؤقت مشترك يسحب منك الوقت بين الغرف،
وبعد كل غرفة تحصل على مفتاح (رموز مشفرة) للعبور إلى الغرفة الموالية.

## التشغيل (Vite)

الملف `vite.config.js` جاهز مع `@vitejs/plugin-react` على المنفذ 5173.

```bash
npm install
npm run dev
```

## بنية المشروع

```
src/
├── App.css               # كل التنسيقات
├── App.jsx               # إدارة الحالة العامة + المؤقت المشترك + العقوبات
├── main.jsx
├── components/           # كل غرفة في ملف مستقل
│   ├── Room1.jsx         # غرفة الصبر (60 ثانية مؤقت مخفي)
│   ├── Congrats.jsx      # غرفة التهنئة (أكمل / أكتفي)
│   ├── Room2.jsx         # فك التشفير خلال 3 دقائق
│   ├── Room3.jsx         # الاختيار خلال 5 ثوانٍ + وقت اللقاء الفرنسي
│   ├── DayRoom.jsx       # استخراج اليوم من درجة الحرارة
│   ├── Room4.jsx         # إدخال كل المفاتيح بالترتيب → الإحداثيات
│   ├── MapRoom.jsx       # الخريطة + تحديد مكان اللقاء
│   ├── FinalRoom.jsx     # رسالة تُمحى بعد 5 ثوانٍ وتُغلق الغرفة
│   ├── Timer.jsx         # مكون المؤقت
│   ├── KeyDisplay.jsx    # عرض المفتاح مع زر نسخ
│   ├── CipherTable.jsx   # جدول مفتاح التشفير (تلميح)
│   └── PenaltyScreen.jsx # شاشة الانتظار العقابي
└── utils/
    ├── cipher.js         # شيفرة الرموز + النصوص المشفرة
    └── clipboard.js      # نسخ النصوص مع بديل متوافق
```

## ملاحظات

- الخريطة (MapRoom) تعتمد على OpenStreetMap Embed وتحتاج اتصالاً بالإنترنت.
- توكن "أكتفي" يُخزن في localStorage ويمنع الدخول حتى يُحذف.
- كل فشل يضيف 3 دقائق انتظار (3 ثم 6 ثم 9…).
